# Shop_TeamWork: Интернет-магазин одежды 

Полнофункциональное веб-приложение для онлайн-магазина одежды с каталогом товаров, панелью администратора и интеграцией платежной системы Stripe. Проект полностью контейнеризирован с помощью Docker для быстрого и удобного развертывания.

##  Технологический стек

* **Бэкенд:** Python, Django 5.2
* **База данных:** PostgreSQL
* **Фронтенд:** HTML, CSS, JavaScript, Nginx (в качестве веб-сервера и reverse-proxy)
* **Платежи:** Stripe API (обработка платежей и вебхуки)
* **Инфраструктура:** Docker, Docker Compose

##  Быстрый старт (Локальный запуск)

Для запуска проекта вам понадобится установленный [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/).

### 1. Клонирование репозитория и сборка
